Privacy Policy — MP2026

Last updated: September 18, 2026

MP2026 is a private, self-hosted tool operated by a single owner for personal use. It is not a public service and does not serve third-party users. This policy explains how the app accesses and handles data when it connects to a Google Account.

1. Google user data we access

With the account owner's explicit consent through Google OAuth 2.0, MP2026 requests access to the YouTube Data API v3 with the following scopes:

  • https://www.googleapis.com/auth/youtube.upload — to upload videos to the owner's own YouTube channels;
  • https://www.googleapis.com/auth/youtube.force-ssl — to manage (for example, update or delete) the owner's own uploaded videos and read the owner's own channel information.

Access is limited to channels that the account owner owns and operates. The app does not access data of any other user.

2. How we use Google user data

Data is used solely to publish and manage the owner's own content (for example, uploading the owner's own short videos to the owner's own channels). It is not used for advertising, profiling, analytics of third parties, or any purpose other than operating the owner's personal publishing workflow.

3. Storage and security

OAuth tokens (access and refresh tokens) are stored encrypted on the operator's own machine and are transmitted only to Google's API endpoints over HTTPS. They are not stored on any third-party server operated by us.

4. Sharing and disclosure

We do not sell, rent, trade, or share Google user data with any third party, except as required to comply with applicable law.

5. Retention and deletion

Tokens remain stored until the owner removes them. The account owner can revoke access at any time at myaccount.google.com/permissions. Revoking access or deleting the locally stored tokens immediately stops all further access by the app.

6. YouTube API Services

MP2026 uses YouTube API Services. By using this app, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

7. Changes to this policy

Any changes to this policy will be posted on this page with an updated revision date.

8. Contact
